    About the 3D film — designed and coded by me

    The backdrop is a 20-second 3D film that I designed and coded myself; it isn’t a template or a stock animation. It runs live in your browser with three.js and WebGL, and designs a real-time messaging platform in the open, from a single server to a global system: a WebSocket gateway and presence in Redis; a load balancer, gateway replicas and a message router; a message store, RabbitMQ and push notifications for offline delivery; encrypted media with a CDN and Lambda thumbnails; group fan-out and contact discovery on Elasticsearch; auth, an end-to-end key server and rate limits; then Kubernetes, Jenkins, Datadog and Kibana — and finally three regions with replicated storage. Every link is a real data path, built with technologies from the CV. The developer at the glass desk is me (IrfanK): before each stage he types the change, and a deploy beam carries it from his screen to the components that land. The same code renders the downloadable films frame by frame, encoding the MP4s in the browser with WebCodecs.
